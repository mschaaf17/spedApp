# 2.0.0 — Mobile classroom workspace

Added responsive workspaces, scoped access, visual student support requests, quick tracking, progress graphs, family sharing, reviewed plan drafts, quiet hours, optional push/AI adapters, and a Chromebook extension. Original source and historical database collections are retained.

Students select supports through large pictures, receive a visual confirmation, and can choose to hear captions. Reading and automatic audio are not required for the basic request path. Educators choose and teach pictures matching each student's actual supports and communication needs.

The demo contains fictional data in the browser session. A live database, HTTPS host, accounts, and optional provider configuration are needed for school use. No native packages, store publication, production migration, real push delivery, or model training was performed.
